1. PROJECT IDENTITY
--------------------------------------------------------------------------------
Name: Triad Care (formerly CareSync)
Tagline: "Care that connects. Responsibility that follows."
Description:
An AI-powered elderly care coordination and accountability platform connecting
elderly individuals, caregivers, and family members.

Problem Statement:
Elderly individuals often struggle with complex multi-drug regimens, forget doses,
misplace doctor prescriptions, or feel alienated from their own healthcare decisions.
Family members living remotely worry and cannot verify whether medications were
actually taken. Meanwhile, professional or informal caregivers receive reminder
pings but lack structured, accountable ways to claim responsibility for follow-ups,
leading to the bystander effect where everyone assumes someone else is checking.

Target Users:
1. Elderly Users (Primary Patient) — e.g., Meera Sharma, 72, living with chronic
   conditions (Type 2 Diabetes, Hypertension, Mild Arthritis). Need high contrast,
   large touch targets, zero cognitive clutter, and sovereignty over their prescriptions.
2. Caregivers — e.g., Riya Patel, professional or visiting caregiver. Need an action-
   oriented queue of unconfirmed/overdue doses, simple one-touch accountability claiming,
   and audit logging.
3. Family Members — e.g., Arjun Sharma, son living elsewhere. Need visibility into
   adherence trends, real-time reassurance of who is following up, and the ability
   to propose prescription adjustments without overriding the patient.

Main Differentiator:
The "I'm handling it" Caregiver Accountability Engine. When a dose is unconfirmed
or overdue, a caregiver explicitly claims responsibility (Calling, Going to check,
Unavailable). The platform permanently decouples dose adherence status from
follow-up responsibility status.

2. ORIGINAL REQUIREMENTS
--------------------------------------------------------------------------------
Core Requirements:
A. Shared Healthcare Profile & Role-Based Access:
   - Three distinct roles: elderly, caregiver, family.
   - Single shared patient profile accessible by authorized memberships.
   - Demo persona login with 4-digit passcodes (1111, 2222, 3333) and instant switcher.

B. Medication Management:
   - Full CRUD: Add, edit, soft-delete medications.
   - Dosage, unit (mg, ml, tablet, etc.), frequency (once_daily, twice_daily, etc.).
   - Timing slots (morning, afternoon, evening, bedtime) generating daily dose schedules.
   - Food interaction / instructions and start/end dates.

C. Medication Adherence Tracking:
   - Doses have explicit statuses: taken, missed, not_confirmed, pending.
   - Non-responsiveness must NEVER automatically classify a dose as missed.
   - Confirmation must store exact timestamp and user ID.

D. Caregiver Accountability ("I'm handling it"):
   - Actions: "I'm calling", "I'm going to check", "I'm unavailable".
   - Statuses: unassigned, accepted, in_progress, resolved, reassigned.
   - Stores caregiver ID, action, accepted_at, resolved_at, notes.
   - Transparent live feed on Family Dashboard.
   - CRITICAL RULE: Claiming or resolving a follow-up must NEVER mark a dose as taken.

E. "Why wasn't it taken?" Reason Logging:
   - When a dose is unconfirmed/missed, allow logging reasons: Forgot, Medicine
     unavailable, Feeling unwell, Unsure / cannot remember, Other (with notes).

F. Doctor Appointment Management:
   - Add, edit, list, and delete doctor appointments with specialty, date/time,
     location, and consultation notes.

G. Medication Change Request & Approval Workflow:
   - Family members proposing prescription changes create a "pending" change request.
   - Active medications remain untouched until the elderly user approves or rejects it.
   - Upon approval, the change is applied to active medications.

H. AI Features (Google Gemini API with graceful demo fallback):
   - AI Prescription Scanner: OCR extraction of medicine name, dosage, frequency,
     instructions from uploaded images via Gemini Vision, with human verification table.
   - Prescription Diffing: Compare extracted items with active patient medications.
   - AI Weekly Healthcare Digest: Synthesize adherence metrics, missed dose reasons,
     and appointments into compassionate plain language.

I. Healthcare Safety Principles:
   - Never recommend extra doses, stopping meds, or diagnosing conditions.
   - Never fabricate missing prescription data or simulate AI as live API calls.
   - Strictly separate clinical facts from AI commentary.

J. UI Architecture (Section 13 Compliance):
   - Functionality-first, clean separation of API/state/types from presentation
     so external UI templates can be dropped in later without rebuilding backend.

7. CURRENT KNOWN ISSUES & LIMITATIONS
--------------------------------------------------------------------------------
1. Gemini Vision API Key:
   Without `GEMINI_API_KEY` set in `backend/.env`, the AI Prescription Scanner and
   Weekly Summary operate in simulated demo mode (`is_demo=True`). This is intentional
   and clearly messaged to the user in the UI.
2. Production Deployment:
   Application currently runs locally using SQLite (`backend/caresync.db`) and Vite dev
   server. Production deployment would require setting up a PostgreSQL instance, running
   Alembic migrations, and building Vite into static assets served via Nginx or FastAPI.
3. Live Email Dispatch:
   Resend / SMTP integration is omitted to avoid claiming emails were sent when running
   locally without credentials.
